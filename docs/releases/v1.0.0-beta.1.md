# Fantasy Cartographer v1.0.0-beta.1

The first public beta of Fantasy Cartographer, a free, self-hostable fantasy
map editor that runs in the browser and keeps your maps on your own computer.

> This is an **early beta**. Please export a backup (`Export → Editable project`)
> of maps you care about, and report anything that breaks.

## Run it

```bash
git clone https://github.com/mercurial20/loremapper.git
cd loremapper
docker compose up -d        # → http://localhost:8080
```

Without Docker, run `npm ci && npm run build && npm run preview`, which serves
the app at <http://localhost:4173>. Node.js 22.12+ is required.

## What's in this release

- **Terrain:** raise, lower, mountain-range, smooth and flatten brushes with
  sizes in km. Seeded generation of continents, islands and archipelagos.
- **Elevation:** heights in metres, a configurable sea level, automatic peak
  detection with heights, contour lines and a height overlay.
- **Biomes:** grassland, forest, farmland, desert, swamp, snow and rock.
- **Drawing:** rivers and roads with editable control points, political
  territories and curved labels.
- **Objects:** 57 built-in illustrated assets, plus import of your own PNG,
  WebP and SVG files into a permanent library with categories.
- **Fog of war:** hide/reveal brushes and a player-view preview.
- **Map styles:** parchment, fantasy atlas, clean political and shaded relief.
- **Storage:** automatic local saving in IndexedDB, multiple maps, and undo/redo.
- **Export:** PNG images (complete map or revealed-only), 16-bit heightmaps, and
  `.fantasymap` project files that can be re-imported.

## Tested

- Clean install from a fresh clone; lint, type-check, 19 unit tests and the
  production build pass.
- `docker compose up -d` serves the app on `localhost:8080`.
- Automated browser runs against the Docker build in Chrome 154, Firefox 157 and
  WebKit 27.2 (macOS) covered:
  - terrain and biome painting;
  - placing and editing objects;
  - importing PNG and SVG assets and replacing built-in artwork;
  - reloading, with maps, assets and the camera position all restored;
  - PNG, heightmap and project exports, and re-importing a project;
  - switching between maps.

  These runs produced no console errors. Firefox logs a few harmless WebGL
  notices.

## Known issues and limitations

- Safari itself, Windows and Linux have not been tested yet (only the WebKit
  engine on macOS).
- Desktop only; no touch support.
- Map resolution is fixed when a map is created: about 11 km per terrain cell
  (Standard) or about 5.7 km (High detail).
- Rivers and roads don't carve the terrain, and territory borders don't snap to
  each other.
- Undo history doesn't survive a page reload.
- Project files of fully generated worlds are about 20–25 MB.
- Maps are stored per browser and per address (origin). Opening the app on a
  different port or hostname shows a separate, empty list of maps.

See the [README](https://github.com/mercurial20/loremapper#current-beta-limitations)
for details, and the [changelog](https://github.com/mercurial20/loremapper/blob/main/CHANGELOG.md).
