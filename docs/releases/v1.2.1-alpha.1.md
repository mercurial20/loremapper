# Loremapper v1.2.1-alpha.1

A small patch: minimal, privacy-focused product analytics on the official site.

**Try it online:** <https://mercurial20.github.io/loremapper/>. Nothing to install, and your maps stay in your browser.

## What's counted

To learn whether people actually use Loremapper, the official online version now
counts five actions with [PostHog](https://posthog.com/):

| Event | When |
|---|---|
| `map_created` | a new map was created |
| `world_generated` | a world was generated |
| `first_edit` | the map was edited (once per visit) |
| `project_reopened` | a saved map was reopened on a new visit (once per visit) |
| `map_exported` | an export file was produced |

Each event is only its name and time.

## What's not

- **Your maps never leave your browser.** Map names, terrain, drawings, labels, seeds,
  coordinates, imported images and files are never sent.
- **Nothing is stored on your device.** There are no cookies and nothing in local
  storage. The anonymous ID lasts until the page is closed or reloaded, and no user
  profiles are created.
- **No automatic tracking.** There are no pageviews, clicks, session recordings,
  heatmaps or error reports. The analytics code is loaded lazily, in its smallest
  build, and contains none of these.
- **Privacy signals respected.** Browsers that send Global Privacy Control or Do Not
  Track skip the analytics entirely.
- **No effect on your work.** If PostHog is blocked, Loremapper works exactly the same.
- **Official site only.** Self-hosted copies and forks have no product analytics.

Like any web request, the service sees your IP address and browser; IP storage is turned
off for this project. Cloudflare Web Analytics keeps counting visits as before. See
*Privacy and analytics* in the README for details.

## Tested

- 76 unit tests, lint, type-check and the production build pass.
- The production build was run at the official address with all outgoing requests
  intercepted. It checked that:
  - each of the five events fires once, at its successful action;
  - nothing else is sent;
  - no map content appears in any request;
  - nothing is stored in the browser.
- With PostHog blocked, with Global Privacy Control, and on localhost, nothing is sent
  and the editor works normally.
- The 19 desktop checks of the editor still pass. The project format is unchanged.
